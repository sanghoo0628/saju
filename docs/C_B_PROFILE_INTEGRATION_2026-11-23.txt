읽기 전용 검사 방법과 범위
최초 검사에서 tx.request의 SELECT FOR UPDATE가 READ ONLY에서 25006으로 거부됐다.
이는 마이그레이션 오류가 아니라 PostgreSQL의 정상 제한이다. 읽기 전용 설정을 풀지 않았다.
최종 검사는 읽기 7개를 실행하고 행 잠금 SELECT는 실행 계획만 검사한다.
재사용 스크립트: scripts/verify-supabase-readonly.ts
프로젝트 ref opt-in과 pooler 대상 검사, CA 검증을 강제하고 오류에 키/URL/사용자 데이터를 출력하지 않는다.
C_READONLY_QA_PROJECT_REF=acghfykdtorpxkbmknja pnpm verify:supabase:readonly
이 명령은 해당 작업 폴더에 실제 .env.local이 있을 때 사용한다.
현재 임시 체크아웃에는 키를 복사하지 않았다. 이번 실행은 Node --env-file로 기존 환경 파일만 읽었다.
