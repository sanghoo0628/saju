사용자 흐름
- 이미 있는 방: 대화 이어가기·무료 → /chat?room=...
- 보낸 pending 요청: 수락 대기 중·요청 확인 → /requests?request=...
- 받은 pending 요청: 받은 대화 요청 확인·무료 → 같은 요청 상세. 결제 확인 버튼 없음.
- 기존 수락/거절 기록: 요청 결과 확인. 환불 또는 새 결제를 추정하지 않음.
- 보낸 pending 요청에는 별도의 결제 상태·대화 권한 확인 버튼 유지. 이전 주문이 환불돼도 서버에서 새 권한 확인을 할 수 있는 기존 경로를 막지 않음. 기존 권한/새 주문 필요 여부는 서버 판단이며 자동 결제는 없음.
- 첫 목록 조회 중/오류/미인증이면 새 권한 확인을 시작하지 않음. 부분 목록은 목록에서 확인하도록 안내.
- 사주 풀이 공급자가 미준비여도 매칭용 양력 생년월일 저장 동의로 프로필·추천에 갈 수 있음을 안내.
- 후보가 없으면 본인 프로필·추천 조건 확인 링크 제공.

선택·권한 경계
- URL 요청 ID는 선택 힌트만 제공. 서버의 학교 계정 인증은 그대로이며, 로그인 사용자의 실제 요청 목록에 있는 항목만 자동 선택.
- 타인/존재하지 않는 ID/오류·초기 조회 상태는 자동 선택하지 않음. URL만으로 별도 요청을 읽거나 권한을 만들지 않음.
- 사용자가 직접 목록을 선택하면 이후 갱신이 URL 힌트로 선택을 덮어쓰지 않음.
- 계정/화면/초기 선택이 바뀌면 기존처럼 컴포넌트 인스턴스와 세션을 새로 구성.
