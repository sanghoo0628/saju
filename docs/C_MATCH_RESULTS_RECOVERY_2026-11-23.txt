무료 추천 조회 지연 복구 (2026-11-23)

발견: CampusChat의 무료 추천 GET만 직접 fetch를 사용하여 응답 헤더나 JSON이
멈추면 로딩이 끝나지 않았다. 결제·채팅의 기존 제한 시간 처리는 적용되지 않았다.

수정: 기존 브라우저 요청 처리를 createBrowserRequest로 공유하여 무료 추천도
15초 제한, 화면 이탈 시 취소, 헤더/본문 전체 제한, 타이머/리스너 정리를 적용했다.
제한 시간 후에는 기존 오류 안내와 다시 불러오기 버튼을 사용한다.
자동 재시도나 주문 생성은 추가하지 않았다. B의 중첩 error 응답과 C의 최상위
code/message 응답을 모두 보존한다. 기존 결제·채팅 클라이언트 API는 유지한다.

로컬 검증: A118개(추천 조회 회귀 6개 포함), C167개, UI24개 통과.
린트·타입 검사 및 별도 복사본의 Next webpack 빌드 통과.
B 검사 144개 통과, postgres-wire 6개는 로컬 listen EPERM으로 실행되지 않았다.
포트가 필요한 검사와 native PostgreSQL 검사는 GitHub CI에서 확인한다.
이전 학교 메일 발송 실패는 별도 SMTP 설정 문제이며 이 변경으로 해결하지 않는다.

공유 DB, 실제 메일 발송, 실제 결제, main 변경 없음.
현재 4300 서버에는 직전 c86b500 빌드가 실행 중이다. 기존 exec 세션 종료가
자동 승인 정책에 거부되어 유지했다. 새 코드의 빌드는 격리된 복사본에서 검증했다.
SMTP 준비 후 다음 실행 시 최신 C 코드로 재시작해 실제 계정 흐름을 확인한다.
