실행 도구
계획 생성은 Git 정보와 체크리스트만 기록하며 검사 단계는 실행하지 않는다.
--run은 lint, 타입, 전체 테스트, Next build, Vite build, HTTP 검사를 실행한다.
--postgres로 native PostgreSQL 검사를 추가 선택할 수 있다.
프로젝트에 고정된 pnpm 버전을 PATH에서 확인한다. shell 문자열을 실행하지 않고 고정된 스크립트/인자만 spawn한다.
각 단계가 실패하면 뒤 단계를 멈추고 자동 재시도하지 않는다.
단계별 제한 시간, SIGINT/SIGTERM 처리, 시작한 Unix 프로세스 그룹의 종료/강제 종료를 포함한다.

결과의 의미
test-results/integration/<고유 실행 폴더>/report.json, manual-checklist.txt, 단계별 log가 생성된다.
실행 Git revision과 dirty 여부를 기록한다. Git 정보가 없으면 null로 남긴다.
선택한 자동 검사가 통과하면 selectedChecksPassed=true다.
fullUserFlowVerified=false, 수동 시나리오 not_run, 정책 decision_required는 자동 변경하지 않는다.
로그는 파일 0600, 폴더는 제한 권한으로 생성하며 Git ignore 대상이다.
원본 .env.local은 읽거나 수정하지 않는다. 예시 변수명과 서비스 접두사로 자식 연결값을 비워 기존 mock/격리 검사로 실행한다.
실제 학교 메일, 공유 DB live QA, HRUM 호출, Groble 청구를 도구 단계에 넣지 않았다.
