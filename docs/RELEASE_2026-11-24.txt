지금 준비한 코드
1. vercel.json: Next.js, 고정 pnpm 설치/빌드, DB와 가까운 sin1.
2. APP_ENV=preview: HTTPS에서만 명시적인 mock 샘플을 사용. 운영에서는 mock 금지 유지.
   VERCEL_ENV=production인데 APP_ENV가 development/preview면 설정 오류로 거부.
3. DATABASE_SSL_CA_PEM: 로컬 파일 경로 대신 클라우드 환경 변수로 공개 CA를 전달.
   기존 DATABASE_SSL_CA_PATH는 로컬에서 유지. PEM이 있으면 우선하며 잘못된 값은 거부.
   TLS 인증서 검증은 끄지 않는다.
4. Groble 완료 이벤트 어댑터: 공식 링크/ref 규칙, raw bytes HMAC, ±5분 timestamp,
   current/previous 서명, 최대24시간의 명시적 이전 키 만료, 상품/금액500/KRW 검증.
   buyer 정보는 내부 결제 형식에 저장하지 않는다.
   이 어댑터는 아직 런타임에 연결하지 않았다. PAYMENTS_ENABLED=true는 계속 거부한다.
