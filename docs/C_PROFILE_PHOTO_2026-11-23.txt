추천 카드 프로필 사진 연결 (2026-11-23)

PR #5 검토에서 B의 ProfileCard.photoUrl이 C 추천 카드에 표시되지 않는 것을 발견했다.
CampusChat이 실제 photoUrl을 MatchProfilePhoto에 전달하도록 연결했다.
새로운 DB/API/스토리지 권한은 추가하지 않는다. 프로필 사진의 서명 URL만 사용한다.

동작
- 사진 있음: 정사각형 영역에 object-fit:cover로 표시.
- 사진 없음 또는 이미지 로드 실패/만료: 기존 기본 아바타 표시.
- URL이 새로 발급되면 이전 실패 상태를 초기화해 새 이미지를 표시.
- 이미지와 대체 아바타의 영역 크기를 같게 유지해 카드 정렬/높이 변동을 방지.
- 대체 텍스트, lazy loading, async decoding, no-referrer 적용.
- 서명 URL을 이미지 최적화 프록시나 별도 저장소에 저장하지 않는다.
- 이번 범위는 무료 추천 카드다. 채팅/결제 아바타 확장은 포함하지 않는다.

검증
- UI 자동 검사 27개(사진 URL/대체 텍스트 및 사진 없음 회귀 2개 추가) 통과.
- 기본 전체 480개(B150+C171+A118+UI27+도구14), HTTP20 통과.
- ESLint, 타입 검사, 격리 Next webpack build 및 Vite build 통과.
- 실제 React 컴포넌트와 실제 CSS를 쓰는 합성 이미지 브라우저 검증:
  정상 이미지, 사진 없음, 404/만료 후 아바타, URL 갱신 후 사진 복구.
- 390px 가로 넘침 없음, 1280px 3열 및 이미지/대체 아바타 제목 정렬 확인.
- React best-practices 스킬로 키에 따른 실패 상태 초기화, 접근성, 불필요한 Effect 없음 확인.
- 검증용 임시 화면/합성 이미지는 정리했다. 사용자 사진 업로드나 공유 DB 쓰기는 하지 않았다.
- 스크린샷은 저장소 밖 work/profile-photo-2026-11-23에 보관.

main 수정/병합 없이 codex/c-payment-chat 브랜치에서만 진행했다.
