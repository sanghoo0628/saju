새 검증

2. 시간 초과 뒤 재전송 없이 HTTP 기록 조회만으로 pending 전송 확인 및 해제.
3. 실시간 연결 중단 중 누락된 메시지를 HTTP 재조회로 복구. 중복 알림은 합치고, 양방향 차단 뒤 HTTP403으로 기록/구독/자동 조회를 중단하며 양쪽 전송·조회 거부.
4. HTTP 인증 만료401 이후 기록/구독 제거, 늦은 이벤트 무시, 추가 전송 거부.
