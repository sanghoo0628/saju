# 사주 API 선택 검토

확인일: 2026-11-16. A 범위의 첫 연결 대상으로 **HRUM 만세력 API**를 선택했다. 요구사항은 공급자가 계산한 원국·오행·용신·강약을 구조화하고, 생시를 아는 사람도 별도 3주 계산으로 B에 전달하는 것이다. 설명문 생성이나 공급자의 궁합 점수는 필요하지 않다. 이 선택은 공급자 계산의 과학적·통계적 매칭 효력을 입증한다는 뜻이 아니다.

정책은 확인일의 공개 안내이며 가입·결제하지 않았다. 실제 호출 단가와 한도는 연결할 계정의 최신 콘솔·요금표에서 확인한다. SAZU의 결과 저장·재사용 권한은 검토한 [API 약관](https://www.sazu.app/legal/api-terms?scope=api)만으로 명확히 확인하지 못했다. 다른 후보 역시 공개 API가 있다는 이유만으로 원본 결과의 무기한 저장·재판매 권한을 가정하지 않는다.

## HRUM 연결 범위

서버는 문서에 있는 partner 엔드포인트를 호출하고, 허용한 필드만 정규화한다. 인증 키를 브라우저로 보내지 않는다. 용신은 공급자의 최종 선정값과 선정 방법을 보존하며 오행 부족량으로 다시 계산하지 않는다. 강약 원점수는 궁합 점수로 변환하지 않는다. 생시 미상이나 공통 매칭 기준에서는 시·분을 전송하지 않고 공급자에게 3주 계산을 요청한다. 상세 4주 결과에서 시주만 삭제하지 않는다.

HRUM의 [공식 문서](https://hrum.ai/docs.html)는 동일 입력 계산 결과를 DB에 저장해 재사용하는 방법을 안내한다. [약관 제11조](https://hrum.ai/terms.html)는 자체 서비스 안의 가공·표시와 서버 경유 호출을 허용하고, 실질적 가공 없이 원시 API를 제3자에게 재공급하는 행위는 금지한다. B 계약은 팀 내부 데이터 경계이며 외부 개발자용 재판매 API로 공개하지 않는다.

기록된 guest 응답은 `tests/fixtures/hrum/`에 있으며, 가상의 테스트 생년월일로 받은 결과에서 필요한 필드만 남겼다. 이 검증은 partner 인증·요금·SLA·저장 허용 범위 또는 운영 서비스 성공의 증거가 아니다. 실제 키가 준비되면 소유자가 승인한 환경에서 partner endpoint 응답과 fixture 계약을 확인해야 한다. 계약 버전은 우리 어댑터 버전이고, 공개되지 않은 HRUM 만세력 엔진 버전을 대신하지 않는다.

운영 전에는 공급자 계정·키, 결과 가공·보관·삭제 조건, 출생정보 외부 전송 고지와 동의, 사용량·한도 정책을 확인한다. 이 외부 설정과 별개로 정규화·3주 B 계약·표시된 mock·오류 처리·로컬 테스트는 진행할 수 있다. B 전달 필드와 `ready/not_ready` 기준은 `FORTUNE_MATCHING_CONTRACT.md`에 정의했다.
