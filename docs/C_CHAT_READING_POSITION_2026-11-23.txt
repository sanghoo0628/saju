C 채팅 읽기 위치 유지
2026-11-23 / codex/c-payment-chat

문제와 변경
기존 Conversation은 메시지 수가 바뀔 때마다 맨 아래로 내려갔다.
지난 대화를 읽고 있으면 새 메시지가 올 때 읽던 위치가 끊길 수 있었다.
이제 현재 위치가 바닥에서 64px 이내면 새 메시지를 계속 따라간다.
그보다 위에서 읽고 있으면 현재 스크롤 위치를 유지하고 최신 메시지 보기 버튼을 표시한다.
버튼을 누르면 맨 아래로 이동하고, 대화 로그에 키보드 초점을 둔다.
사용자가 직접 아래로 내려온 경우에도 안내 버튼은 사라진다.
내 메시지 전송이 확인되면 해당 메시지를 볼 수 있도록 최신 위치로 이동한다.
메시지가 비워지거나 방이 바뀌면 해당 화면의 추적 상태도 초기화된다.

구현 범위
packages/payment-chat-ui/src/ChatPanel.tsx: 바닥 근접 상태를 ref로 추적한다.
메시지 목록 수신 때 최신 ID 변경을 확인하고, useLayoutEffect에서 따라가기 상태인 경우만 스크롤한다.
대화 로그를 tabIndex=0으로 키보드 탐색 가능하게 하고, 버튼은 명시적 클릭 때만 초점을 이동한다.
packages/payment-chat-ui/src/styles.css: 안내 버튼과 로그 키보드 초점 표시를 추가했다.
polling·Realtime·서버 메시지/API/인증/차단 동작은 변경하지 않았다.
이 안내는 현재 화면의 이동 기능이며 서버 읽음 표시나 읽지 않은 메시지 수 기능은 아니다.
새 패키지·마이그레이션·DB 컬럼은 없다.

브라우저 검증
사용자가 사용 중인 4174 데모 대신 별도 4193 데모 + 4194 로컬 프록시를 사용했다.
가상 요청 수락 후 메시지 35개를 별도 메모리 저장소에 준비했다. 실제 계정·결제는 사용하지 않았다.
1. 방을 열면 최신 기록으로 이동: 하단 간격 -0.5px(브라우저 소수점 반올림).
2. 위쪽으로 스크롤한 뒤 상대 답장 체험:
   이전 scrollTop=2243.5, 이후 scrollTop=2243.5로 읽던 위치 유지.
   콘텐츠 높이는 3308→3374px로 늘었고 최신 메시지 보기 버튼이 표시됐다.
3. 안내 버튼 클릭: 하단 간격 0px, 대화 로그에 초점 이동, 안내 버튼 제거.
4. 바닥에서 새 답장 수신: 하단 간격 0px 유지, 메시지 37개.
5. 바닥에서 1045px 위로 이동한 뒤 직접 메시지 전송:
   내 메시지가 표시되고 하단 간격 0.5px, 메시지 38개로 정상 이동.
소수점 1px 이내 차이는 브라우저 레이아웃 반올림이다.
